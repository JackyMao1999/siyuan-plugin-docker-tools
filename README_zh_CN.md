# Docker端工具集

[English](./README.md) | **简体中文**

1. 支持 PDF 导出
2. 支持打印
3. 支持飞书知识库同步（飞书文档 → 思源笔记，单向）
4. 支持浏览器书签同步（Chrome / Edge / Firefox / Safari → 思源数据库，单向）

## 飞书知识库同步

将飞书知识库（Wiki）/ 云文档中的文档同步为思源笔记文档，仅支持「飞书 → 思源」单向同步。

### 功能特性

- 五种同步来源：**飞书知识库（Wiki）**、**我的文档库**、**可访问的 Wiki 页面**、**存储（云盘）**、**指定链接**。
- **我的文档库**：使用用户身份直接浏览个人页面树，支持分页与递归同步。
- **可访问的 Wiki 页面**：使用用户身份自动发现或按关键词搜索页面，按所属空间分组；只有页面/子目录权限时也可作为同步入口。结果不保证完整，可使用关键词或指定链接补充。勾选分组只同步已发现页面及所选递归范围，不会尝试同步整个空间。
- 支持同步飞书**知识库（Wiki）**：按知识空间浏览目录树，可递归同步子文档并保留层级结构。
- 支持同步飞书**存储（云盘）**：浏览云空间根目录或指定文件夹。
- 支持**指定链接**：粘贴文档 `/docx/`、旧版文档 `/docs/`、知识库 `/wiki/`、文件夹 `/folder/` 链接直接解析同步。
- 支持**增量同步**：按飞书文档的编辑时间判断，内容未变化时自动跳过。
- 递归子文档、同步图片/附件/画板、增量同步、添加来源默认开启，统一在插件设置中调整。
- 支持**图片 / 附件本地化**：将文档中的图片与附件下载并保存到思源资源目录。
- 支持**文档内嵌电子表格**：同步为可编辑的思源表格，第一行作为表头，保留单元格内容及接口返回的计算结果；不保留计算能力、合并单元格和复杂样式，不受素材下载开关影响。读取失败时保留提示，具体原因见同步日志。
- 支持**公式块**：飞书原生公式块，以及段落中的 `\[...\]` / `$$...$$` 文本会转换成思源公式块；同段多条公式分别拆块，保留其间正文及样式。原生行内公式保持行内，代码和链接不自动转换；表格单元格中的公式使用行内形式。
- 支持写入指定的目标笔记本与根路径；已同步过的文档会原地更新，不会重复创建。

> 更新插件后，如需替换旧文档中的电子表格占位提示或公式文本，请关闭「增量同步」重新同步。同步会覆盖思源中对应文档的内容。此功能仅适用于新版文档中的内嵌电子表格，不包含独立电子表格链接或多维表格。

### 访问身份：应用身份 vs 用户身份

| 身份 | 能看到什么 | 说明 |
| --- | --- | --- |
| **应用（机器人）身份**（默认） | 只有**被授权给应用**的知识库 / 文档 | 云文档「我的空间」是应用自己的空间，通常是空的 |
| **用户身份**（推荐） | **你自己**的云文档、你有权限的知识库 | 需要先完成一次 OAuth 用户授权 |

切到用户身份：插件设置 → `飞书访问身份` 选「用户身份」，`授权回调地址` 填与飞书后台
「安全设置 → 重定向 URL」完全一致的地址 → 点击 `打开授权 / 授权管理` →
点击「使用推荐回调地址」，把该地址原样添加到飞书后台，然后在浏览器同意授权。
保持思源授权对话框打开，插件会自动交换并保存令牌，无需复制链接。
桌面版临时监听本机地址（默认 `http://127.0.0.1:18879/feishu-callback`）；浏览器版使用当前思源站点下的
`/plugins/siyuan-plugin-docker-tools/feishu-callback.html`。两种客户端的回调地址分别保存，在飞书后台各登记一次即可；重启或切换客户端不会自动改写已保存的地址。
浏览器版请使用固定的思源域名和端口，只有站点地址实际变化时才需要更新对应回调。
浏览器版需在同一浏览器授权并允许弹窗。手动回填仍可使用，但需粘贴本次授权的完整回调网址（含 `code`、`state`）。
默认不申请 `offline_access`；未取得刷新令牌时，访问令牌到期后需重新授权。此默认设置变更不会撤销已有授权。
详见插件设置中的 **使用帮助**（搜索「用户身份」）。

### 能同步哪些位置（飞书接口限制）

| 位置 | 能否列出 | 说明 |
| --- | --- | --- |
| 存储 · 云盘根目录 | ✅ | 「存储（云盘）」来源，留空即浏览官方所说的「云空间根目录」 |
| 知识库（Wiki） | ✅ | 「飞书知识库（Wiki）」来源，列出接口允许访问的空间；仅有页面权限的入口用「可访问的 Wiki 页面」发现 |
| 任意文档 / 文件夹 | ✅ | 「指定链接」来源：粘贴 `/docx/`、`/wiki/`、`/folder/` 链接直接解析 |
| 共享空间 | ⚠️ 需链接 | 无「列举共享空间」接口；把该文件夹的浏览器链接粘到「指定链接」或「文件夹 token / 链接」即可 |
| 「我的文档库」 | ✅ 用户身份 | 使用「我的文档库」来源直接读取页面树，与云盘「我的空间」分开 |
| 仅获授权的 Wiki 页面/子目录 | ✅ 用户身份 | 「可访问的 Wiki 页面」自动发现 / 关键词搜索，或使用「指定链接」；不保证能列出所属空间的全部内容 |

### 使用步骤

1. 在[飞书开放平台](https://open.feishu.cn/app)创建「企业自建应用」，获取 **App ID** 与 **App Secret**。
2. 为应用开通以下权限（**权限管理 → API 权限**），**开通后必须发布版本**：

   **应用（机器人）身份**
   - `wiki:wiki:readonly`（查看知识库）
   - `docx:document:readonly`（查看新版文档）
   - `drive:drive:readonly`（查看云文档，图片/附件下载也依赖此权限）
   - 可选：`board:whiteboard:node:read`（把画板 / mermaid 图导出为图片）
   - 可选：`docs:document.content:read`（同步旧版文档，只能取纯文本）

   **用户身份**（需额外完成一次 OAuth 授权，授权时由插件申请）
   - `wiki:wiki:readonly` `docx:document:readonly` `drive:drive:readonly`（同上三项，改成用你自己的权限读取）
   - `board:whiteboard:node:read`（画板 / mermaid 导出为图片）
   - `offline_access`（可选，**默认不申请**；需先在飞书后台开通，再在授权范围中手动添加，用于获取 refresh_token 自动续期）
   - ⚠️ 用户身份下「后台开通 ≠ 已授权」：**新增权限后必须重新授权**才会生效，否则相关接口报 `99991679`；
     需要用用户身份同步**旧版文档**时，还要在授权对话框的「授权范围」里手动补上 `docs:document.content:read`
3. 在飞书中将目标知识库/文档授权给该应用（应用机器人需加入对应知识空间或文档协作者）。
4. 在思源中打开 **插件设置**，填写 `飞书 App ID`、`飞书 App Secret`，并按需选择 `飞书域名`（国内版 feishu.cn / 国际版 Lark）。
5. 点击顶栏插件图标 → **飞书知识库同步**（或使用命令 `飞书知识库同步` / 快捷键 `Ctrl+Alt+F`）。
6. 在弹窗中选择同步来源、知识空间、目标笔记本与根路径，勾选需要同步的目录/文档，点击 **开始同步**。

> 💡 不确定怎么配置？在 **插件设置** 中点击 **「打开帮助 / 配置向导」**（或顶栏菜单 →「使用帮助」），即可检索各功能的配置步骤，以及飞书需要开通的权限清单（支持一键复制）。

> 说明：插件通过思源内核的 `forwardProxy` 接口转发请求，避免浏览器跨域限制；所有请求均使用你填写的应用凭据，不会上传到第三方服务器。

## 浏览器书签同步

把浏览器（Chrome / Edge / Firefox / Safari）导出的书签同步进思源**数据库块**，每条书签是一行独立记录，支持增量。

### 功能特性

- 支持 Netscape 书签格式 HTML（各浏览器「导出书签」通用），文件选择 / 拖拽两种方式，可一次导入多个来源。
- 拖入的书签文件**自动保存副本到工作区 `/data/bookmarks/`**，下次打开对话框自动加载——Docker 版无需填写任何路径。
- 目标为**数据库块**，书签以**独立行**写入；列结构：网站名（主键，第一列）、网站链接（链接列）、标签（多选，按**内容自动分类**——工具 / 网盘 / 资源 / 工作 / 电子书 / 博客 / 开发 / 有趣 / 论坛 / AI / 音乐，规则文件 `data/bookmarks/tag-rules.json` 可编辑定制；书签文件夹层级作为补充，都没命中时按域名兜底）、描述。
- 目标数据库下拉框自动列出全部数据库，新建后点「刷新」即可选到。
- **增量同步**：按内容 hash 判断，未变化的书签跳过，变化项原地更新，不产生重复行；相同 URL 跨来源合并为一行。
- **自动整理列**（每次同步的固定前置步骤，无需按钮、幂等）：补建缺失列、主键改名「网站名」并置于首列、把思源自带的单选模板列（「标签 / 单选」）原地转成多选（值保留）、删除残留的空单选孤儿列与旧版遗留「来源」列、统一列顺序为 网站名 → 网站链接 → 标签 → 描述。
- **描述自动抓取**：导出文件没带说明时，可经内核网络代理读取目标网页的 `<meta description>` 填入（结果按 URL 缓存，失败不覆盖）；网页是 JS 壳页拿不到 meta 时用**书签标题兜底**，描述列不留空。
- 可选**清理已消失的书签**：源文件删除的书签同步删除数据库对应行（默认关闭）。
- 全程解析在前端完成，**Docker / 浏览器 / 移动端可用**。

### 使用步骤

1. 在浏览器书签管理器里**导出书签**为 HTML 文件（各浏览器入口见内置帮助）。
2. 顶栏插件图标 → **浏览器书签同步**（快捷键 `Ctrl+Alt+B`）：
   - 拖入 / 选择刚导出的 HTML，勾选要同步的文件夹（下次打开会自动加载）；
   - 在「目标数据库」下拉框选择数据库（没有的话先在文档里 `/数据库` 插入一个）；
   - 确认字段映射——缺列 / 模板默认列名都会在「开始同步」时自动建好、整理好，无需任何手动操作。
3. 点击 **开始同步**。书签即成为数据库中的行；之后重新导出再拖一次即可增量更新。勾选「抓取网页描述」可自动填入目标网页的 meta description。

> 💡 为什么不能直接读取浏览器书签数据库？插件运行在浏览器沙箱内，没有文件系统权限，无法访问 Chrome 的 `Bookmarks` JSON 或 Firefox 的 `places.sqlite`；「导出书签 HTML」是所有浏览器唯一通用的读取通道。插件会把拖入的文件自动保存为工作区副本（宿主挂载卷 `data/bookmarks/` 内可见），免去 Docker 下配置路径。

> 说明：本功能仅「浏览器 → 思源」单向导入；反向把思源数据库导出成书签 HTML、以及定时自动同步，规划在后续版本。

实现依据：[获取知识空间子节点列表](https://open.feishu.cn/document/server-docs/docs/wiki-v2/space-node/list)（支持 `my_library`）、[搜索 Wiki](https://open.feishu.cn/document/server-docs/docs/wiki-v2/search_wiki)。这两个新来源复用现有用户授权，不额外要求 `search:docs:read`。
