
# Docker端插件库

1. 支持 PDF 导出
2. 支持打印
3. 支持飞书知识库同步（飞书文档 → 思源笔记，单向）

## 飞书知识库同步

将飞书知识库（Wiki）/ 云文档中的文档同步为思源笔记文档，仅支持「飞书 → 思源」单向同步。

### 功能特性

- 支持同步飞书**知识库（Wiki）**：按知识空间浏览目录树，可递归同步子文档并保留层级结构。
- 支持同步飞书**云文档**：浏览「我的空间」或指定文件夹。
- 支持**增量同步**：按飞书文档的编辑时间判断，内容未变化时自动跳过。
- 支持**图片 / 附件本地化**：将文档中的图片与附件下载并保存到思源资源目录。
- 支持写入指定的目标笔记本与根路径；已同步过的文档会原地更新，不会重复创建。

### 使用步骤

1. 在[飞书开放平台](https://open.feishu.cn/app)创建「企业自建应用」，获取 **App ID** 与 **App Secret**。
2. 为应用开通以下权限（权限管理 → API 权限）：
   - `wiki:wiki:readonly`（查看知识库）
   - `docx:document:readonly`（查看新版文档）
   - `drive:drive:readonly`（查看云文档，图片/附件下载也依赖此权限）
   - 如需同步旧版文档，额外开通 `docs:document:readonly`
3. 在飞书中将目标知识库/文档授权给该应用（应用机器人需加入对应知识空间或文档协作者）。
4. 在思源中打开 **插件设置**，填写 `飞书 App ID`、`飞书 App Secret`，并按需选择 `飞书域名`（国内版 feishu.cn / 国际版 Lark）。
5. 点击顶栏插件图标 → **飞书知识库同步**（或使用命令 `飞书知识库同步` / 快捷键 `Ctrl+Alt+F`）。
6. 在弹窗中选择同步来源、知识空间、目标笔记本与根路径，勾选需要同步的目录/文档，点击 **开始同步**。

> 💡 不确定怎么配置？在 **插件设置** 中点击 **「打开帮助 / 配置向导」**（或顶栏菜单 →「使用帮助」），即可检索各功能的配置步骤，以及飞书需要开通的权限清单（支持一键复制）。

> 说明：插件通过思源内核的 `forwardProxy` 接口转发请求，避免浏览器跨域限制；所有请求均使用你填写的应用凭据，不会上传到第三方服务器。
